# 2026/10/17
## Q1 synchronized 和 ReentrantLock 的 3 个主要区别？什么时候必须用后者？
1.synchronized自动释放锁，ReentrantLock需要主动释放锁
2synchronized不能重入，必须释放后才能重新占有锁，ReentrantLock可以重入
3 synchronized性能低
## Q2 CAS 是什么？它有什么著名的缺陷（ABA）？
cas是自旋锁，容易出现死锁
## Q3 用一句话描述 AQS 的构成（提示：一个变量 + 一个队列）
volatile int state + 双端队列
## Q4 公平锁为什么比非公平锁慢？
需要等待队列中的其他对象，存在上下文切换
## Q5 volatile 能保证什么、不能保证什么？
volatile保证可见性和有序性，不能保证原子性
